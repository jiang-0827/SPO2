# STM32F407 血氧饱和度 (SpO2) 采集与算法

把原本跑在 STM32F103 上的血氧算法移植到 **立创·梁山派 天空星 STM32F407VET6**，驱动血氧模拟前端
采集红光 / 红外脉搏波，实时计算血氧饱和度与脉率，并通过 USART1 把结果送到上位机
「串口波形小工具」显示波形与参数。

---

## 1. 硬件

| 项 | 说明 |
|---|---|
| 主控 | 立创·梁山派 天空星 STM32F407VET6（LQFP100，168 MHz） |
| 前端 | 血氧模拟前端板（光电二极管 + TIA 运放 + 恒流驱动） |
| 上位机链路 | **外接 USB-TTL 模块**（天空星 Type-C 只接了原生 USB PA11/PA12，**没有板载 USB 转串口**） |

### 1.1 接线

| 传感器信号 | F407 引脚 | LQFP100 脚位 | 模式 | 作用 |
|---|---|---|---|---|
| `VSIG` | PA5 | 29 | ADC1_CH5 模拟输入 | 放大后的脉搏波 |
| `DAI`  | PA4 | 30 | DAC_OUT1 模拟输出 | LED 恒流 / 光强控制 |
| `IR_CS`  | PC4 | 33 | 推挽输出 | 红外 LED 选通，高电平点亮 |
| `RED_CS` | PC5 | 34 | 推挽输出 | 红光 LED 选通，高电平点亮 |
| `CAP` | 接 3V3 | — | — | 基线钳位开关（PMOS 栅极），置高 = 钳位常闭 |
| `VCC` / `GND` | 3V3 / GND | — | — | 供电 |

USART1：`PA9 (TX)` → USB-TTL 的 RXD，`PA10 (RX)` → TXD，`GND` ↔ `GND`，**115200 8N1**。

> ⚠️ PA4 / PA5 在天空星引脚图上同时标注为 `SPI_CS` / `SPI_CLK`。本工程把它们配成模拟模式，
> 因此**不能同时使用 SPI1**。

## 2. 采样时序（200 Hz）

TIM2 挂在 APB1（84 MHz），`PSC = 83`、`ARR = 4999` → 84 MHz / 84 / 5000 = **200 Hz**，
中断里累加 `g_tim2_5ms_flag`，主循环每 5 ms 做一次 `SPO2_SamplePair()`：

```
阶段0  暗电平采样（两路 LED 均灭）      → rawDark
阶段1  点亮红光 → 延时 150 µs → 采样    → rawRed   （等 TIA 运放建立稳态）
阶段2  熄灭红光 → 延时 100 µs 弛豫放电   （抑制双通道光电串扰）
阶段3  点亮红外 → 延时 150 µs → 采样    → rawIr
```

光强由 DAC 控制，默认 **110**（范围 40 ~ 600）。`SPO2_AutoGainControl()` 每 200 次采样
（1 s）调整一次，把两路 DC 均值维持在 1500 ~ 2400 之间，防止运放饱和。若要与官方参考
固件对齐，可注释掉 AGC 调用、固定光强 110。

## 3. 算法管线（`alg/SPO2_Algorithm.c`）

1. **脱落检测**（双重判据）
   - `PROBE_OFF`：红光/红外与暗电平的差值都 < 35（无光耦合），或 ADC 越界（< 30 / > 4060），持续 20 次采样。
   - `FINGER_OFF`：ADC 接近饱和（> 3500）或过低（< 100），或超过 600 个采样周期未检测到脉搏峰。
2. **DC 基线跟踪**：一阶低通，`DC_ALPHA = 0.992`。
3. **AC 提取 + 滤波**：`raw - DC` → 8 Hz 二阶巴特沃斯 IIR → 10 点滑动均值。
4. **动态寻峰寻谷**：带自适应生理不应期（95 ~ 140 样本）与双倍频次拦截。
5. **R 值计算**：`R = (AC_red_pp / AC_ir_pp) × 1000 × 0.825`，8 点中值滤波。
6. **查表标定**：11 档 R 值表（580 ~ 880）映射到 SpO2 99% ~ 90%。
7. **脉率**：`PR = 60 × 200 / 峰间隔样本数`，8 点中值滤波。

显示信号 `fDispRed / fDispIr = 滤波后交流分量 + 500`，即基线在 500 上下跳动的脉搏波。

> 标定系数与阈值是按参考硬件调的，**换板子需要重新整定**，血氧数值仅供参考。

## 4. 串口输出（`app/main.c` 里的 `OUT_MODE`）

| `OUT_MODE` | 目标上位机 | 格式 |
|---|---|---|
| **`1`（默认）** | 课程「串口波形小工具」 | 文本，**每行恰好 2 个数** `%.2f,%.2f` |
| `2` | VOFA+ | JustFloat：4 × float32 小端 + 4 字节帧尾 `00 00 80 7F` |
| `3` | 任意串口助手 | 调试文本，含原始 ADC（`rawRed/rawIr/rawDark`），降频 ~10 Hz |

### 模式 1 的细节

该工具是**按数字解析文本流**的：一行里第 1 个数画到第一道波形（红 = 红光通道），
第 2 个数画到第二道波形（蓝 = 红外通道），遇换行重新计数。**每行只能发 2 个数**，
多发会把波形配错（表现为一个假的 fs/4 方波）。

右侧参数栏用工具自己的命令，最多 5 格，每 100 次采样（2 Hz）刷新：

| 格 | 名称 | 内容 |
|---|---|---|
| 1 | `SpO2` | 血氧值 + R 值，如 `98 0.65` |
| 2 | `pulseRate` | 脉率 |
| 3 | `status` | `OK` / `FINGER_OFF` / `PROBE_OFF` / `CALC` |
| 4 | `off` | 脱落判断：`CONNECTED` / `PROBE_OFF` / `FINGER_OFF` |
| 5 | `DAC` | 当前光强 |

参数名用 `{{id,name}}` 在开机时设置一次（工具会本地保存，不宜频繁发送）。标签文本里
不要含数字，否则会被当成波形点。

### 上位机设置（波形小工具）

**波形数量 = 2**、波特率 **115200**、**采样率填 200**（填成 100 会让频率读数减半）。

```

  spo2_hw/      前端驱动：GPIO/DAC/ADC 初始化、4 阶段采样时序、AGC

```
